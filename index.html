Chargement de l’application…
📱 La page reste sur cet écran ou paraît vide ?

Vous l’ouvrez sans doute depuis l’app Fichiers de l’iPhone : son aperçu (« Coup d’œil ») affiche le fichier mais n’exécute pas les applications. Rien n’est cassé — il faut juste l’ouvrir dans un vrai navigateur :

Sur iPhone / iPad (recommandé)
1. Installez l’app gratuite Documents (de Readdle) depuis l’App Store.
2. Dans Fichiers, partagez ce fichier vers Documents (ou copiez-le dedans).
3. Ouvrez le fichier depuis l’app Documents : l’application complète se lance, avec sauvegarde automatique.

Autre option : toute app disposant d’un navigateur intégré capable d’ouvrir les fichiers HTML locaux. L’aperçu de Fichiers et « Ouvrir avec Chrome/Edge » ne fonctionnent pas pour les fichiers locaux sur iOS.

Sur ordinateur : double-cliquez simplement le fichier (Chrome, Edge, Firefox, Safari).

Vos données restent sur votre appareil. Pensez à télécharger régulièrement une copie depuis l’application.
